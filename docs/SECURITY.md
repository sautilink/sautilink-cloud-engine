# Security reporting

If you believe you found a security issue in Cloud Engine, report it privately
through [SautiLink Contact](https://sautilink.com/contact).

Include the affected public page or documented endpoint, the approximate time,
the observed behavior and safe steps to reproduce it. Redact passwords,
session details, access tokens and other people's personal data.

Do not publish an exploit or expose private data in a public issue. Test only
with accounts and systems you are authorized to use. Do not disrupt the
service or access another user's information.

The service's [Terms](https://cloudengine.sautilink.com/terms) and
[Privacy Policy](https://cloudengine.sautilink.com/privacy) explain applicable
usage and data practices. This reporting guide does not promise a bounty or
authorize otherwise prohibited access.
