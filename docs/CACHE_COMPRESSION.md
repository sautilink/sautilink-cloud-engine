# Cache and compression inspector

Open [Cache and Compression](https://cloudengine.sautilink.com/tools/cache)
and enter a public website URL.

The tool shows observed cache directives, response validators, content encoding,
content length and related response headers. Use these observations to review
how a page may be stored, refreshed or transferred.

Results can differ with request headers, location, login state and
intermediaries. Missing compression headers in one response do not prove that
every browser receives uncompressed content. This tool does not measure a
compression ratio or replace a performance benchmark.

Use the [API guide](API.md) for supported integrations.
