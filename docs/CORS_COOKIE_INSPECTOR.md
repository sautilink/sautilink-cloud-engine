# CORS and cookie inspector

Open [CORS and Cookies](https://cloudengine.sautilink.com/tools/cors) and
enter a public website URL.

The tool shows observed CORS response headers and cookie attributes such as
Secure, HttpOnly, SameSite and Path. Cookie values are not shown.

These are observations from the checked response. The tool does not simulate
every browser origin, request method or preflight, so it cannot guarantee that
all cross-origin requests will succeed or fail.

Use the [API guide](API.md) for supported integrations.
