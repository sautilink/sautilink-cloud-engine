# Cloud Engine on Telegram

Open [@sautilinkcloud_bot](https://t.me/sautilinkcloud_bot) and send `/start`.

## Check a website

Choose **Check a Website**, send a public domain or URL, then select the check
you want. Results provide navigation to run the check again, open a Full Audit,
or inspect another target.

## Preferences

Use `/settings` to choose report detail, developer-oriented target information
and the start view. Use `/lang en` or `/lang sw` for English or Kiswahili.
Developer Mode provides additional information about the website being checked.

## Useful commands

| Command | Purpose |
| --- | --- |
| `/start` | Open your start view |
| `/help` | Open help and tools |
| `/settings` | Manage your preferences |
| `/lang en`, `/lang sw` | Select a language |
| `/id` | View your Telegram identifiers |
| `/proxy` | Browse current community proxy connections |
| `/proxy status` | View proxy-directory status |
| `/proxy help` | Read connection guidance |
| `/contact` | Open support options |

For proxy details, see the [proxy guide](PROXY_DIRECTORY.md). Visit
[Cloud Engine](https://cloudengine.sautilink.com) for the full website workspace.
