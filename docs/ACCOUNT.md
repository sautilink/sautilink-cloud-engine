# SautiLink Account help

Cloud Engine's public tools can be used without creating an account.
Account options, where available, help you manage your own service preferences.

## Sign up and verify

Use the official account form, provide your details and follow the verification
instructions sent to your email address. Enter the current code in the
verification screen. Do not share sign-in codes, recovery links or passwords.

An **Email verified** label confirms the email address; it is not a public
notability or platform-verification badge.

## Account access

Use the official sign-in and recovery options. If a recovery or verification
step fails, request a fresh code or link and use the latest message.
Contact support if the problem continues.

## Communication preferences

Optional product updates are controlled separately from account-security
messages. Review your preferences in the account screen. Read the
[Privacy Policy](https://cloudengine.sautilink.com/privacy) for data information.

Support: [SautiLink Contact](https://sautilink.com/contact).
