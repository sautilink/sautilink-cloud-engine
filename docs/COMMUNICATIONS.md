# Messages from SautiLink

Account verification, password recovery and other necessary service messages
support the operation and security of your account.

Optional product updates are separate. Review the available communication
preferences in your account and use the unsubscribe option provided with
optional email updates.

Use only official SautiLink links when signing in. Never share your password,
verification code or recovery link with someone who contacts you.

For help with an unexpected or suspicious message, use
[SautiLink Contact](https://sautilink.com/contact). Remove passwords, codes and
other private credentials from any screenshot you share.
