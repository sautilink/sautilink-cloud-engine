What each status means
Active
Passed a recent MTProto connection check.
Unstable
Recent checks have mixed results. A reliable connection is not confirmed.
Offline
Several consecutive connection checks failed.
Unverified
A current supported connection check is not confirmed.
Stale
The last confirmation is too old to recommend a connection.
