# SautiLink Cloud Engine

Website, domain and network diagnostics from SautiLink Corporation.

- **Use the service:** [cloudengine.sautilink.com](https://cloudengine.sautilink.com)
- **Telegram bot:** [@sautilinkcloud_bot](https://t.me/sautilinkcloud_bot)
- **Product updates:** [@drcharlesofficial](https://t.me/drcharlesofficial)
- **Support:** [SautiLink Contact](https://sautilink.com/contact)

## Get started

Open the website and choose a tool, or send `/start` to the official Telegram
bot. Enter the public website, domain or IP address requested by the selected
tool. English and Kiswahili are supported.

Cloud Engine can help review DNS, website response headers, email-domain
configuration, HTTPS, SEO, mobile presentation and related public signals.
Results describe the observations made during the check; they are not a
guarantee of security, availability or delivery.

## Telegram proxies

Send `/proxy` to view current **Connect Proxy** buttons. Use **Next**,
**Previous** or **Refresh** for more choices. The same directory is available
at [Telegram proxies](https://cloudengine.sautilink.com/tools/proxy).

These are community proxies. A recent successful check does not guarantee that
a proxy will work from every network or remain available. Telegram asks you to
confirm the connection. [Proxy guide](docs/PROXY_DIRECTORY.md).
